# Public v1.0.0 release notes

This release **renames the already accepted v2.9 feature baseline** into the public semantic version `1.0.0` without changing the Lua keyboard processor. It adds a clean public schema ID (`quickbridge`) and one-step installation script for new users.

## Verified on user's Windows system

- `h` + NumPad `1`, then `h` + Left Shift -> `h1h`
- `hi` + NumPad `+` -> `hi+`
- `hello` + NumPad `123` -> `hello123`
- `of` + top-row `2` + Shift+top-row `1` -> `你們`

The **new public installer** has not been run on a second clean Windows machine yet; it has source-level/static checks only. OpenVanilla association fidelity beyond the 442 manually observed positions is not proven.
